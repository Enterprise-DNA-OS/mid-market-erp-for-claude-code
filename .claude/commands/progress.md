# progress

Update a task's percent complete.

Run `npm run erp -- progress <project> <task> <percent>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Take the figure from the project manager, never estimate it. It drives earned revenue and the next claim.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
