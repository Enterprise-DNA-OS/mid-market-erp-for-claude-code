# order

Show one order with its lines and follow-up notes.

Run `npm run erp -- order <code>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Read this before changing, chasing or confirming an order.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
