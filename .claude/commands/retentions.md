# retentions

List retention money held from subcontractors with its state: held, first report due, report due, release overdue or released.

Run `npm run erp -- retentions`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

For anything not held or released, offer /draft-retention-report or /release-retention. Read docs/compliance.md for the NZ rules.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
