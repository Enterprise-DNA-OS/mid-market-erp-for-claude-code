# claims-due

List active projects with unclaimed work and no claim for 30 days.

Run `npm run erp -- claims-due`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Offer /claim for each. Confirm percent complete with the project manager first.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
