# items

List stock items with unit, cost, price, reorder point and preferred supplier.

Run `npm run erp -- items`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Read only.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
