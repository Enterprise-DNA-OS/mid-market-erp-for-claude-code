# log

Record a factual follow-up note on an order or project.

Run `npm run erp -- log <order or project> "note"`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Write what happened, who said it and when.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
