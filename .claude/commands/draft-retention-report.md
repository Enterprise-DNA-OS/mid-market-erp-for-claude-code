# draft-retention-report

Draft the retention money report for a subcontractor into drafts/.

Run `npm run erp -- draft-retention-report <subcontractor>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Nothing sends. After a person sends it, record it with /report-retention.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
