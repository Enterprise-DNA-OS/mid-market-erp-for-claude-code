# invoice-balance

Copy an invoice balance verified in the accounting ledger.

Run `npm run erp -- invoice-balance <invoice> <amount paid> "ledger evidence"`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never estimate a balance.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
