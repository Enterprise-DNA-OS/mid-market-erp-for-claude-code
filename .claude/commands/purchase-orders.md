# purchase-orders

List purchase orders by due date with the project they are bought for.

Run `npm run erp -- purchase-orders`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Read only. Amounts exclude GST.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
