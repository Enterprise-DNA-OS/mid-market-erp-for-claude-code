# tasks

List every project task with percent complete, budget, actual, committed and forecast cost, and earned revenue.

Run `npm run erp -- tasks`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Read only.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
