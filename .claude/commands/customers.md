# customers

List customers with contact details, tax ID, credit limit and payment terms.

Run `npm run erp -- customers`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Read only. Use `--json` when another command needs the IDs.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
