# report-retention

Record that the retention money report went to the subcontractor.

Run `npm run erp -- report-retention <retention> [--on=YYYY-MM-DD]`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Only after the report was actually sent by a person. The next one is due in three months.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
