# release-retention

Record retention money released to the subcontractor.

Run `npm run erp -- release-retention <retention> [--on=YYYY-MM-DD]`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Only after payment. Nothing here pays anyone.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
